STARS OF THE LYLAT SYSTEM

ライラット星系に存在する5つの恒星に関する観測記録。星系の全天体はこれらの恒星のいずれかの重力圏に属しており、各恒星の性質が周辺惑星の環境・文化・軍事情勢を大きく規定している。

ライラット・プライム ソーラ ハクティバ パラニド ドグマ・セントラル 関連: セクター / 人種 / 勢力 / 用語

ライラット・プライム LYLAT PRIME — ライラットα星

B2型 / 青色大型恒星 / セクターα

ライラット星系の全ての天体と星雲の中心に位置する、B2型に属する青く巨大な恒星。スペクトル観測データによると極大質量の星でありながら、想定される星の寿命をはるかに超えて40億年以上も輝き続け、今なお安定を保っている謎の多い天体でもある。

巨大な恒星ゆえに出力される熱量が非常に高く、周回する惑星のほとんど全てが恒星圏セクターαから大きく離れた軌道を公転している。星間航路図や軍事勢力図にライラット・プライム自身が滅多に描かれないのはこのためである。コーネリアをはじめとする主要惑星群は、いずれもこの星の絶妙な距離の恩恵を受けて文明を築いた。

ソーラ SOLAR — ライラットβ星

M3型 / 橙色小型恒星 / セクターο / 詳細記事 ►

M3型に属するオレンジ色の小型恒星。ライラット・プライムの伴星であり、惑星が密集するエリアを公転している。アクアス、ゾネス、フィチナはこの星を公転しており、マクベスは近日点を通過する際にソーラと接近するタイミングがある。

特殊なセクター磁場の影響で通常の恒星とは全く異なる組成を示しており、プロミネンスが飛び交うプラズマ状の表面の真下を、溶岩のような液体岩石が対流するという「恒星と惑星の中間」のような特異な性質を持つ。コアワールドより外側の惑星はソーラの干渉を受けているとされ、ライラットの文明・文化にも大きな影響を与えてきたと考えられている。

ハクティバ HACTIVA — ライラットγ星

F1型 / 白色中型恒星 / セクターϻ

F1型に属する白い中型の恒星。ライラットδ星パラニドとは互いに狭い距離で周回軌道を持ち、「双子の太陽」と呼ぶべき関係にある。星系外縁を周回しながら独立した星系を保持しているため、その重力圏に属するエラダード、キュー、パペトゥーンは、内惑星群とは全く異なる文化圏を形成している。

上記3惑星はハクティバ通商連合を構成しており、ライラットウォーズには武器供与などの支援のみに関わりをとどめているとされるが、パペトゥーンにはコーネリア共和国の士官学校を誘致し、エラダードではベノム帝国向け軍事物資製造ラインを建設するなど、両陣営の間で怪しげな取引を続けている。

パラニド PARANID — ライラットδ星

F2型 / 白色中型恒星 / セクターϻ

F2型に属する白い中型の恒星。ハクティバと対をなす「双子の太陽」のもう一方であり、太古に滅びたパラニド神聖帝国と、知識の神の名を冠する星である。爬虫類系人種たちにとっては、この星を見上げると何か本能に訴えかけてくるものを感じるという。

ハクティバとパラニドの中間位置には特殊な磁場がワームホールを形成しているとの報告があり、外宇宙との接続の可能性を指摘する学者もいる。しかし到達の困難さに加え、ハクティバ通商連合の探査船による執拗な妨害があり、コーネリア共和国側は現在も状況を掴めずにいる。

ドグマ・セントラル DOGMA CENTRAL — ライラットε星

Mx7型 / 深紅小型恒星 / セクターϸ / 詳細記事 ►

Mx7型に属する深紅の小型恒星。ライラット星系の最外縁、真の辺境というべき位置にあり、周囲をドグマを覆い隠すように暗黒星雲が周回しているため、観測に成功すること自体が稀である。

他の4恒星のさらに外側に位置し、接続されたワープドライブ航路も最古の廃止路線の終着点より外にあるため、この星や周辺宙域にアクセスする者は皆無となっている。数年前からドグマ近辺で謎のコンタクト信号が観測されているとの報告が挙がっているが、戦時下の状況もあり実質的に放置されているのが現状である。
