RACES OF THE LYLAT SYSTEM

ライラット星系には様々な人種が存在し、それぞれが得意な分野をもって文明を興してきた歴史を持つ。現在でこそ最低限の秩序が保たれているが、根底にある差別意識はいまだ根絶できておらず、星系の外縁に行くほどそれは顕著になる。確認されている人種は細かいものまで合わせると320種を超えるとされる。

アヌビソイド ANUBISOID — 犬型人種

主な出身・居住地: コーネリア / パペトゥーン

犬型人種とも称され、現在のコーネリア連合共和国の最大派閥とされる人種。温厚で仲間想いでありながら、大きな危機には仲間と結束して立ち向かう勇気を併せ持ち、その性質が戦争を止める一助になったことは想像に難くない。

過去にベノムの遺跡で発掘された壁画や資料には、古代の滅びた種族、通称オーバーロードを引き連れて先頭に立って進む姿が描かれており、ライラット文明の起源に最も近い人種であるというのが通説となっている。スターフォックスのフォックス・マクラウド、カタリナ駐留軍のビル・グレイ、傭兵ウルフ・オドネルなどはこの人種である。

アルフォイド ALPHOID — サル型人種

主な出身・居住地: 旧・惑星ステファノー / フィチナ / コーネリア（移民街区ニッコータウン）

サル型人種と称され、星系内ではフィチナのサルジーナヤ州など比較的寒冷な土地に生活している人種。全人種の中でも突出した知能を発揮する者が多く、居住の難しいフィチナでの生活もその知性と技術を活用してのものである。

本来は温暖で居住環境の整った第6惑星ステファノーに本拠地を持つ人種だったが、グランベル国との戦争で惑星破壊兵器ギャラクティック・ノヴァ・ブラスターが使用され、惑星もろとも文化と人口の大半が失われた悲劇の歴史を持つ。生き残った人々は星系各地へ離散し、二世紀余りを経た現在もフィチナの寒冷地やコーネリアシティ外れの移民街区ニッコータウン（通称ステファノー街）などに、強い結びつきの共同体を保っている。このためコーネリア連合共和国の建国にグランベルが携わっていることへの拒否感が根強く、ベノム帝国への離反者が最も多い人種となっている。帝国を率いるアンドルフ・ボウマン、その甥アンドリュー・オイッコニーなどはこの人種である。

バステトイド BASTETOID — 猫型人種

主な出身・居住地: 星系全域（定住地を持たない者が多い）

猫型人種と称される人種。あまり派閥を作らず、各々が自由に生きる者が多いとされる。縛られることを嫌う気質ゆえか星系中に居住しており、「ライラットではネコジャラシと猫はどこにでもいる」という諺ができたほどである。

決まった惑星に定住しない者が多いためか運送業に就く者が多く、大手運送業「ブラックカーゴ」や星間宅配ピザ「ピザ・キャット」など商売で成功する者も多い。カタリナ州で惑星移住計画を指揮する開拓庁や軍事拠点にはバステトイドが多いとされる。キャット・モンロー、パンサー・カルロッソ、ミユ・リンクスはこの人種である。

キューソイド KYUSOID — ネズミ型人種

主な出身・居住地: キュー / ハクティバ通商連合圏

ネズミ型人種と称され、ハクティバ通商連合の息のかかったエリアや惑星キューを根城にしている人種。小柄で非力だが卓越した計算力と商才を発揮する者が多く、商業界の有名人を最も多く輩出している。同時に、利益のためには手段を選ばない狡猾さも併せ持つとされる。

他人種より体格が圧倒的に小さく自衛のためにボディガードを雇う者が多い一方、被差別人種として不当な扱いを受けることも多く、特にバステトイドとの相性は最悪である。惑星キューの裏社会を牛耳るマフィアアルペジオや武器商人も、ほとんどがこの人種の人物である。

ホルソイド HOLSOID — 鳥型人種

主な出身・居住地: 星系全域

鳥型人種と称され、バステトイドと同様に自由を好む性質から様々な惑星・地域で生活している人種。ただし自由奔放で軽薄さも併せ持つバステトイドと異なり、ホルソイドは誇りや義理を何よりも重んじ、腕っぷしも強い。短気で細かいことを気にしない者が多く、怒らせると大変なことになると言われる。ライラット星系で最も人気の格闘技クロスバウトの宇宙チャンピオンもこの人種が最多である。

遥か昔に外宇宙からオーバーテクノロジーを受信したのはこのホルソイドであり、パラニド神聖帝国では爬虫類人種を従えて神のように崇められていたと記録されている。ただし現時点では証拠が何も残されておらず、仮説の一つに過ぎないとされる。スターフォックスのファルコ・ランバルディはこの人種である。

ゼートイド ZETOID — イノシシ型人種

主な出身・居住地: コーネリア・ローザリンド州 / マクベス

イノシシ型人種と称される。山岳地帯の多いコーネリア共和国ローザリンド州やマクベスで生活している人種。元来より屈強な体力と鋭い嗅覚による鉱物採掘の洞察力に長け、それに応じて精錬やロボティクスなどの技術力も有する、高いポテンシャルを持つ人種とされる。

労働と管理を一元して任せられる人材が多いことからマクベスでは鉱山採掘業を担ってきた。ベノム帝国が真っ先にマクベスを奪取したのは、武器生産ラインの確保よりも、ゼートイドの高い技術力を手中に収めるためだったとまで言われている。ピグマ・デンガーはこの人種である。

ヘケトイド HEKETOID — 両生類型人種

主な出身・居住地: アクアス / ゾネス / コーネリア

両生類型人種と称され、アクアス・ゾネスを中心に水辺を好んで生活する人種。元々は旧・タッドー共和国の主要人種を構成しており、卓越した科学技術で水中都市を建設していたが、現在は人口の大半がコーネリアに移住。自然と調和した建築技術を活かし、コーネリア都市部の素晴らしい景観を作り出している。

技術と知識を尊ぶ姿勢がアルフォイドと通じ合うようで、連合結成以前からステファノーとは友好関係にあった。また、迫害されてきたパラノディアンに融和的な態度で接した唯一の勢力でもあり、両人種の信頼関係はかなり深い。スターフォックスのメカニック、スリッピー・トードはこの人種である。

パラノディアン PARANODIAN — 爬虫類型人種

主な出身・居住地: 星系全域 / タイタニア / フォルトナ

爬虫類型人種の総称。彼らの遠い祖先が信仰していた知識の神パラニドの名を冠した種族であり、星系内の至る所に住んでいる。ライラット星系ではこのパラノディアンは長く迫害の対象となっており、今なお差別や偏見を持つ者が少なくない。種族的に粗野で衝動性が高い傾向があることも、偏見を助長する要因となってしまったようだ。

融和的な態度で接してくれたのはタッドー共和国のみだったため、ヘケトイドとの信頼関係はかなり深いものとなっている。タイタニア、フォルトナにも派生民族が住んでいるとされるが、両惑星は外界との通信すら難しく研究は進んでいない。スターウルフのレオン・ポワルスキーはこの人種である。

セレノイド SELENOID — ウサギ型人種

主な出身・居住地: 不明（希少人種）

ウサギ型人種と称され、星系内でもほとんど確認されていない希少人種。パラノディアンと並びルーツや文明、過去の変遷が一切判明していないが、一説によれば「月兎」と呼ばれる極めて強力な戦闘民族だった可能性が示唆されている。

彼らの深い洞察力や瞬発力はこの闘いのセンスによるものと言われるが、詳細は不明。ライラット星系ではごく少数が確認されているのみで、今となってはその真実を知る者もいない。スターフォックスの参謀ペッピー・ヘア、そして共和国軍ヴォーパル隊を率いるアンバー・シルフェイド少佐はこの人種である。

ポラリソイド POLARISOID — 熊型人種

主な出身・居住地: コーネリア・グランベル州／タイガリーブス州 / フィチナ・サルジーナヤ州

熊型人種と称され、主にコーネリアのグランベル州、タイガリーブス州で生活している人種。大柄で力が強く、おおらかで優しい性格の持ち主が多いが、ホルソイドと並んで「決して怒らせてはいけない人種」と言われている。体色が白いシロクマ系の種族は、寒冷なフィチナのサルジーナヤ州に住む者も多い。

人口はあまり多くないが、その体躯と忠義心からアヌビソイドやアルフォイドの要人のお付きを務める者や、惑星キューで警備員を務める者が多く、総じてボディガードに高い適性を持つようだ。コーネリア防衛軍のエースパイロットにして偵察部隊隊長も兼任した軍の先鋭ベアー・ノウグッチーニ、サルジーナヤ州の副州知事ベアーチェはこの人種である。

無類の鮭好きとして知られ、コーネリアでは川に鮭が遡上する季節になると「サーモン休暇」を取得する者が多い。また冬眠種族のため、冬になると寝てしまう者も多い。

アスタロソイド ASTAROSOID — 馬型人種

主な出身・居住地: カタリナ / コーネリア

馬型人種と称される人種。広い場所を好む気質で知られ、カタリナ州が植民地として開放された際には真っ先に志願し、同州で人口最多の人種となった。地平線まで続くカタリナのサバンナは、彼らにとってまさに理想の入植地だったのである。走ることそのものが文化に深く根付いており、州の収穫祭で行われる大平原横断競走は星系有数の祭事として知られる。

持久力や身体能力は全人種で最高を記録するが、その高さに反比例するように手先は不器用である。指が1本の蹄であるため、就学年齢に入ると専用のマニピュレータ義手を装着するのが通例であり、これはサイバネティック技術の民生応用として最も普及した例の一つに数えられる。

アポフィソイド APOPHISOID — 蛇型人種

主な出身・居住地: 星系全域（少数） — 広義にはパラノディアンの一種

蛇型人種と称され、広義にはパラノディアンの一種であるが、他種族とは一線を画す人種のため本データベースでは別記事とする。アポフィソイドは星系で最も進んだサイバネティック技術を有する種族であり──同時に、最も強烈な嫌悪と忌避を集める人種である。元来より開拓団に含まれていなかった人種とされ、星系各地の神話に共通して登場する「楽園を追われる原因を作り出した生物」に酷似していることから、根深い差別の対象となってきた。

手足のないフォルムは他のどの人種とも異なる形態であり、文明生活を営むために彼らが自らの手足を作り出したことこそが、サイバネティック技術発展の始まりだったとされる。彼らの義手・義足の技術が負傷した軍人の人生を助け、そのサイボーグ技術が現役で活用され続けていることは、誰にも変えることのできない事実である。

ハクティバ圏を牛耳るマフィアアルペジオが唯一恐れているのはアポフィソイドのアサシン集団であり、この人種への過剰なまでの差別意識は、アルペジオが意図的に星系中へ流したデマが原因とも考えられている。独立星系連合（IGA）で連合軍を幾度も窮地に陥れたナハシュ・ギルバスター将軍はアポフィソイドでありながらサイバネティクスによる全身サイボーグであり、「六刀流のギルバスター」として星系中で指名手配されていたことでも有名だった。

その他のマイナー人種 MINOR RACES

上記の主要人種以外にも、アルマジロ型人種「モーフォイド」（ローリィ・ポリーナ）、ウシ型人種「ミノソイド」（バイソン・レッドフォード）など、細かい人種は多岐にわたる。全て合わせると320種を超えるとされ、その全容は共和国の統計局ですら把握しきれていない。
